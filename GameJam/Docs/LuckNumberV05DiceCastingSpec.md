# Luck Number v0.5 策划案｜骰子开奖与同号合击

**交付对象**　Unity 程序、战斗表现、测试  
**实施基线**　v0.4 命中充能原型，场景 `Assets/Scenes/Pinball.unity`  
**交付状态**　开发规格。概率为数学值，技能参数为首轮试玩值。

## 1. 玩家规则

**单张可以直接出。两张及以上合出时，所有牌必须同号，元素可以不同。出几张就自动掷几颗骰子，只要有一颗摇中牌号，整组一起发动。**

玩家从手中选出同一号码的1～5张牌，可以只选其中一部分。第一张牌自动确定本次匹配的号码。留在手中的牌持续提供球体附魔。打出的牌失去对应附魔，并按实际张数支付补牌成本。

| 玩家选择 | 适用局面 | 代价与收益 |
|---|---|---|
| 留牌 | 球的附魔足以处理当前敌群，或手中有空位可以等下一张 | 保持持续火力，有机会凑出同号 |
| 单出 | 需要腾出一格，愿意用一张装备赌一次局部攻击 | 只花一张，掷一骰，命中发动标准技能 |
| 同号合出 | 敌群密集，值得牺牲多件装备争取全场技能 | 同号牌共进退，命中一次即可全部发动，整组也可能落空 |

## 2. 出牌与开奖

1. 点击第一张牌后，将其他号码的牌置灰。可继续点选同号牌，再点已选牌可撤选。撤选最后一张后解除号码锁定，可重新选择任意号码。点击 `Cast N` 提交实际选中的 N 张。选择期间，牌的附魔继续生效。
2. 仅在正常游玩期间接受提交。扣牌前校验所选卡牌数量为1～5、实例互异、全部仍在手中，且所有牌号与首张相同。任一条件失败即拒绝整批，手牌、骰子随机状态及补牌账目均保持提交前的值。
3. 接受提交时，锁定本批卡牌和本桌存活怪物的元素、位置与生成顺序。一次性移除所选卡，刷新球体附魔，追加 N 张的补牌成本。
4. 自动掷 N 颗独立、公平的六面骰，记录其中与本组牌号相同的骰子数量 H。
5. 根据下表为整组判定一次释放档位。骰面直接决定档位，取代 v0.4 的定时幸运号、Q抽签与短路判定。落空时整组消耗，本次技能效果为零。
6. 建议用0.45秒战斗时间揭晓骰面，随后同步播放技能和结算首波效果。摇骰期间玩家可以操作挡板，下一次出牌在本批揭晓后开放。后续波次与燃烧可跨批次执行。

### 整组判定

| 已出同号牌 N | 命中骰数 H | 整组结果 |
|---:|---:|---|
| 任意 | 0 | 落空 |
| 1 | 1 | 标准技能 |
| ≥2 | 1 | 全场合击，所有已出牌发动 |
| ≥2 | ≥2 | 头奖，所有已出牌发动强化全场技能 |

每张已出牌在整组命中时贡献一次技能。判级时 H≥2 统一按头奖处理。手里留着的同号牌只提供附魔。

**结算例**　手中有 `6电弧、6火花、2震波`。选6电弧和6火花合出，2震波留在手中。系统掷两骰。

- 骰面 `6、2` → 两张6发动全场雷暴和烈焰，手中的2震波继续提供附魔。
- 骰面 `6、6` → 两张6共同获得头奖。
- 骰面 `2、5` → 两张6消耗，整组落空。

## 3. 为什么合出更强

N 张同号牌合出时，整组命中率为 **1 − (5/6)ᴺ**。

| 同样消耗两张牌 | 至少一张发动 | 两张均发动 | 平均发动张数 |
|---|---:|---:|---:|
| 两张6分开单出，各掷一骰 | 30.6% | 2.8% | 0.333 |
| 两张6一起出，共享两骰 | 30.6% | **30.6%** | **0.611** |

两张6合出时，两张均发动的机会是分开打的 **11倍**，且命中即获得全场档。三张同号合出的整组命中率为 **42.1%**。这里的“发动”统计技能开奖结果，实际伤害还取决于敌方元素和目标存活情况。

## 4. 技能、颜色与目标

普通怪生成时确定元素。首轮三种元素等概率。蓝色雷怪免疫雷，红色火怪免疫火，震波色怪免疫震波。免疫覆盖对应伤害和状态。球体基础碰撞为无属性伤害，三种怪均可受到4点碰撞伤害。怪物显示元素图标、对应颜色与独立血条。

**持有附魔**按手中同元素卡数量计算。电弧从碰撞点电击附近其他可受电击的怪，火花点燃可受燃烧的直接目标并可向附近扩散，震波眩晕可受控制的范围目标。复用 v0.4 的半径、伤害、持续时间与同类数量公式。每种元素先筛出可受影响目标，再应用距离和数量上限。命中同色怪时，碰撞点仍能向周围异色怪触发附魔。眩晕沿用现有前后排队和球体碰撞处理。

**主动技能**使用以下首轮参数。标准档选离危险线最近的最多4只可受影响怪物，同距离按生成顺序选择。全场和头奖覆盖提交快照中本桌所有可受该元素影响的怪物。后续波次跳过已死亡目标。

| 元素 | 标准 | 全场 | 头奖 |
|---|---|---|---|
| 电弧 | 局部，2轮雷击 | 全场，3轮雷击 | 全场，4轮雷击 |
| 火花 | 局部，燃烧4秒 | 全场，燃烧6秒 | 全场，燃烧8秒 |
| 震波 | 局部，1轮冲击，眩晕1.5秒 | 全场，2轮冲击，眩晕2秒 | 全场，3轮冲击，眩晕3秒 |

雷击每轮12伤害，间隔0.25秒。主动燃烧每秒6伤害，每0.5秒结算一次。冲击每轮8伤害，间隔0.35秒，首轮施加眩晕。

**重复元素合并**。整组共用同一档位。按元素选择可受影响目标，每多一张同元素的电弧或震波加1轮，每多一张火花加2秒燃烧。眩晕使用本组档位的时长。每张牌在每个目标上只计一次，不同元素分别结算。

例如两张6号火花一起命中一个6，全场可燃目标获得 **8秒** 燃烧，即全场档6秒加第二张火花的2秒。若是6号雷与6号火，蓝怪受火、红怪受雷、震波色怪可同时受雷与火。零可用目标时照常支付成本，结果显示命中与实际覆盖数。

## 5. 补牌与状态

- 手牌上限5张，每张新牌的号码1～6、装备类型三选一，分别等概率生成。开局测试手牌采用 `6火、6震、2雷、4雷、5火`，可在第一局演示同号合击。
- 补一张的基础需求是100点。**一批打出 N 张，当前补牌需求追加 50×N 点**。满手开始时，首张需求为100＋50×N。已有的充能进度继续累计。补回一张后还有空位，下一张需求为100。溢出可进入下一张，满手清零。
- 缺牌时自然充能每秒10点，每次有效充能碰撞统一加2.5点。单怪充能冷却1秒，所有来源和球共享滚动1秒16点上限。仅直接物理命中提供碰撞充能，致死碰撞计一次。
- 按平均12.5点/秒换算，从满手一次打两张，约在16、24秒补回。一次打三张，约在20、28、36秒补回。实际间隔由有效碰撞决定。
- 暂停和发球等待冻结充能、揭骰、状态及待发波次。掉命保留已扣成本、充能进度和已提交的骰面。重开清空选择、开奖和待发效果。正常游戏结束后停止战斗结算。

## 6. 交互与表现

- **常态**　卡面显示大号数字、元素颜色和图标。手中出现同号时，在对应数字旁显示对子标记。牌位顺序只用于显示。
- **选牌**　首张选中后突出同号可选牌，异号牌置灰并禁选。按钮显示 `Cast 3 · Roll 3 dice`。预览整组命中率、命中后的技能范围、消耗后的球附魔和追加充能需求。零张时提交按钮禁用。
- **开奖**　显示本组选中牌的缩略图与真实骰面。命中牌号的骰子和整组牌同时亮起，整批显示 `Miss`、`Hit`、`Full Field` 或 `Jackpot` 中的一种。
- **反馈**　普通攻击强调局部目标，全场点亮可受影响敌群，头奖显示额外雷击、持续火焰或多圈震波。同批技能使用统一连杀记录，按实际致死来源计分，每只普通怪50分。
- **首次教学**　`Play one card or combine cards of the same number. Roll one die per card. One match activates them all.`

## 7. Unity 接入

| 现有入口 | 本轮职责 |
|---|---|
| `Hud`、`GameManager.UseCard` | HUD 锁定首张牌号，战斗入口独立校验整批同号。单张调用同一批次流程。接受提交后清空选择，重复点击只生成一个批次 |
| `GameManager`、`LuckTuning` | 一次锁定牌、目标和成本，一次生成 N 个骰面。统计与首张牌号相同的骰子数 H 判级，替换定时幸运数字与旧 Q 概率表。调试支持指定完整骰面序列 |
| `SkillCast`、`EquipmentResolver` | 从批次生成各元素的目标、波次和状态计划，按目标合并同元素贡献。提交到揭晓期间不接受第二次提交，揭晓后可与上一批持续效果并行 |
| `Enemy`、`Spawner` | 使用怪物元素作为技能资格，替换旧怪物号码匹配。基础碰撞、状态与击杀仍经统一入口 |
| `RechargeAccount` | 按张数记一次批次成本，支持已有进度、溢出和限流。在碰撞附魔结算后补牌，新牌从下一次碰撞生效 |
| `CombatVfx`、试玩统计 | 骰面与战斗结果共用一次随机采样。记录批次数、耗牌张数、同号组大小、各档次数、覆盖人数、击杀及0～1张手牌持续时间 |

## 8. 程序验收

| 固定输入或操作 | 通过条件 |
|---|---|
| 单出 `6雷`，分别指定骰面 `[3]`、`[6]` | 前者落空，后者为标准雷击；两次分别消耗一张、掷一骰 |
| 打出 `6雷＋6火`，指定 `[1,6]` | 同一颗6激活两张，全场雷火各自结算。留在手中的第三张6不参与本次开奖 |
| 打出 `6雷＋6火`，指定 `[6,6]` | 获得头奖，雷4轮、火8秒；怪物按元素分别免疫 |
| 手中有 `2火、6雷、6火`，先选6雷，再点2火 | 2火置灰，点击后仍只选中6雷。可追加6火。撤选全部6号后可选2火 |
| 绕过界面，向战斗入口提交 `2火＋6雷` | 整批拒绝。两张牌仍在手中，骰子随机状态和补牌账目与提交前一致，技能发动次数为0 |
| 打出两张6火，指定 `[6,2]` | 可燃目标获得8秒主动燃烧，火怪受到该批火焰伤害为0 |
| 枚举两骰全部36种结果 | `6＋6` 有25种落空、10种全场合击、1种头奖。单出一张6只掷一骰，最高为标准技能 |
| 满手且有三张6，一次打出这三张，分别测试整组落空和整组命中 | 两种结果的累计补回门槛均为250／350／450。满手、暂停、掉命及滚动充能上限按第5节处理 |
| 在揭晓前暂停并恢复，或快速重复点提交 | 恢复后使用同一批骰面，只扣一次牌、只收一次成本。重开后旧批次不能再造成伤害 |

**试玩重点**　用同样两张6比较分两次单出和一次合出，记录两种打法的有效覆盖、击杀、越线与低装备时间。观察玩家何时拆对救场，何时保留对子等待整组爆发。
