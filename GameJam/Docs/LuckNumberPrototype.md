# Luck Number v0.3：号码限定附魔

运行场景：`Assets/Scenes/Pinball.unity`。现有球桌、挡板、回球、怪物生命40、碰撞伤害4、击杀50分、生成频率、下降速度、命中冷却与生命规则保留。

## 本轮玩法

- 手牌不再按时间攻击。球对普通怪物的一次有效物理碰撞，会同时触发持有的各类附魔；按“装备类型＋号码”分组计算N，每组只影响与卡牌号码一致的怪物。被球直接撞到的怪物不必同号，基础碰撞伤害不受限制。
- 电弧：碰撞点3米内，除直接被撞目标外，最近 `min(N+1,5)` 只同号敌人各4伤害；异号敌人不作为目标或跳跃节点。
- 火花：同号直接目标燃烧4/秒、持续3秒；额外点燃2.5米内最近 `min(N-1,3)` 只同号敌人。
- 震波：半径 `1.2+0.25*(N-1)`，只对同号怪物施加被动眩晕0.35秒。眩晕只停下降，不停球碰撞。
- 球上的蓝色电流、火焰拖尾和环形光纹随剩余装备与短路状态变化；旧的燃烧、眩晕及已释放技能不因消耗卡牌消失。
- 主动技能：雷暴每轮12伤害，间隔0.25秒；烈焰6/秒；冲击每轮8伤害、间隔0.35秒，同次只施加一次眩晕。Q只决定规模，正值不直接作为伤害。
- Q<0：该元素球体附魔短路2～4秒；Q=0：哑火。不治疗怪物、不退牌、不减出牌代价。
- 主动技能不限制号码，也不额外加入同号怪：低、中强度只覆盖由Q决定的最近目标，高强度覆盖释放时全场。目标锁定，后续新怪不加入，死者不被替换。
- 补牌：基础8秒，每次出牌将下一张额外推迟4秒。满手连出三张后，20、28、36秒逐张补回。
- A / 左箭头、D / 右箭头控制挡板；R 暂停／重开。手牌不能排序。

## 已确认的规则细节

- 用户确认：被动眩晕期间不接受被动刷新；主动震波可延长。眩晕结束后进入2秒被动免疫，主动可绕过该免疫；重复主动眩晕取较大剩余时间，不相加。
- 用户确认：低装备状态为手牌剩余 **0～1张**。
- 被动和主动燃烧分别保存到期时间，按统一0.5秒节拍结算较高DPS；刷新不重置跳数。刷新同类燃烧不会缩短已有剩余时间，被动燃烧不能延长主动高伤害。
- 多次短路取更晚的恢复时间，不缩短已有短路。
- 怪物由统一前后队列移动管理器在物理步更新；中心距离满足半径之和加0.1米，不依赖推挤、不追补等待期间距离。异号后排可能因前排眩晕而排队，但不会显示眩晕或获得眩晕免疫。

## 界面与调试

界面保留全英文。拖牌显示普通／幸运、短路和全场概率、金色被动同号组、低／中主动覆盖区间、全场范围、消费后同类型同号码的数量与效果，以及下一张补牌的前后倒计时。

顶部按元素显示号码组及各组数量，卡牌标注自身号码组的N；短路倒计时仍按类型显示。结果区显示技能、Q、当前／总轮次或燃烧时长、击杀数。左侧显示本局出牌次数、时间加权平均手牌、0～1张持续时间及死亡原因。

选中 GameManager：Luck 配置全部附魔、强度映射、状态、基础补牌及每次追加延迟。Inspector 底部开发工具可设置幸运数字、固定下次Q（一次）、补入指定牌、生成指定号码怪物、记录试玩统计。选中 Enemy 可开发设置其号码。

结束与重开时 Console 自动记录本局统计；开发入口仅编入 Editor 或 Development Build。

## 号码限定补充验证

新增检查通过：文档中的6电弧／2火花／4震波示例；同类异号各自N=1、同号重复强化；无关的较近目标不占名额；消耗一个号码组最后一张时其他号码组保留；短路仍按类型停用；三个主动技能均能影响异号最近目标，且不加入远处同号怪；异号后排仅排队、没有眩晕和免疫。原有状态、分波、成本、暂停及真实物理碰撞回归检查也通过。

## 原有验证

Unity 6000.6.8f1 编译无错误；已通过以下检查：

- `LuckyPinball > Luck Number > Check Card Rules`：两表合计320,000次抽样；Q5／40／90的覆盖、轮数、时长与四舍五入；短路映射和被动数量上限。
- `LuckyPinball > Luck Number > Run Acceptance Checks (Play Mode)`：无碰撞不攻击、多类附魔、非递归、致死碰撞位置保留、统一燃烧节拍、强弱燃烧分离、被动眩晕不刷新与免疫、主动绕过免疫、分轮伤害、目标锁定、队列安全间距与独立横向路径、补牌成本、暂停与等待状态。
- 独立3D物理场景：真实 `OnCollisionEnter` 击杀直接目标后仍伤害附近目标，命中记录仅增加一次。
- 实际 Pinball 场景：最后一张震波消费后球光纹立即消失；电弧短路不影响火花；Q90雷暴每0.25秒伤害12，四轮共击杀初始3怪、得分150。
- 实际落球：保留补牌债务、主动燃烧、眩晕、短路及待发波次；等待期间全停，重新发球后按剩余时间继续，已有烈焰不因火花全部消耗而消失。
- 实际重开：恢复固定5张手牌、3命、零分、零统计、零短路与零待发技能，幸运剩余10秒、无补牌债务。
- 已检查运行截图的分档预览、球附魔、分轮电链、状态、短路与统计。未执行WebGL打包。

## 出牌成本对照

`LuckyPinball > Luck Number > Compare Play Policies (Play Mode)` 可重跑五个种子的两策略脚本化遭遇模拟。它运行真实战斗逻辑、队列、概率和补牌，但使用固定命中节奏，**不模拟挡板与落球，不等同人工试玩**。

当前规则下的最新结果见 `Docs/LuckNumberV03Balance.md`。保持每次追加4秒，未根据简化模拟自动调参。正式平衡判断还需玩家操作下的落球和决策记录。
