# Luck Number v0.5：骰子开奖与同号合击

场景：`Assets/Scenes/Pinball.unity`。界面继续全英文。

## 操作与规则

- 点击卡牌选择；首张锁定号码，异号置灰且禁选。再次点击可撤选；撤空后解除锁定。
- 同号可以只选部分，元素可以混合。选择期间牌仍在手中，继续提供附魔。
- 点击 `Cast N · Roll N dice` 提交；单张也走同一个批次入口。
- 扣牌前校验数量1～5、实例互异、均在手中且同号。非法整批不会改变手牌、骰子随机状态或充能账目。
- 接受后一次扣牌、按N追加50×N充能需求、锁定敌人元素／位置／生成顺序，并一次生成N个公平六面骰。
- 0.45秒有效战斗时间后揭晓。无同号骰：Miss；单张命中：Hit；多张只有一颗命中：Full Field；至少两颗命中：Jackpot。
- 开奖前不能提交第二批，挡板与战斗继续；揭晓后可与旧批次波次及燃烧并行。暂停与发球等待冻结揭晓和战斗时间。

## 敌人与技能

怪物不再显示旧号码，生成时等概率确定雷／火／震波元素，以图标、蓝／红／紫色和独立血条显示。自身元素的伤害和状态免疫。基础碰撞仍为无属性4伤害。

持有附魔按同元素总数N合并，号码不影响被动；先过滤免疫，再按碰撞位置距离、生成顺序和数量上限选择目标。命中同色怪仍可向附近异色怪触发附魔。原燃烧、眩晕免疫和安全排队规则保留。

|元素|Hit|Full Field|Jackpot|重复同元素卡|
|---|---|---|---|---|
|Arc / Thunderstorm|最多4只合格敌人，2轮|全场3轮|全场4轮|每额外一张+1轮|
|Spark / Inferno|最多4只，燃烧4秒|全场6秒|全场8秒|每额外一张+2秒|
|Shockwave / Impact|最多4只，1轮，晕1.5秒|全场2轮，晕2秒|全场3轮，晕3秒|每额外一张+1轮，眩晕不叠时长|

雷每轮12伤害／间隔0.25秒；火6 DPS／0.5秒跳伤；震波每轮8伤害／间隔0.35秒，仅首轮眩晕。每元素锁定自己的可受影响目标；后续新怪不加入，死亡目标不替补。各元素与燃烧共用整批连杀记录，每只死亡仍只记50分。

## 充能与状态

基础100；一批N张追加50×N，已有进度保留。补回一张后若仍缺牌，下一张100；溢出继续，满手清零。

缺牌时自然10/秒，有效充能命中统一+2.5，不再有同号充能奖励。单怪1秒冷却、全部来源和球共用滚动1秒16点上限。碰撞附魔结算完毕后才补牌，新牌从下次碰撞生效。

失去生命保留已提交骰面和成本；结束停止结算；重开清空选择、开奖和所有待发效果。

## 开发入口与测试

GameManager Inspector 的 Developer Tools：输入完整骰面，如 `1,6`、`6,6`；骰面数量必须等于提交数量，非法输入不会消耗调试序列。也可补入指定卡或生成指定元素怪物。

- `LuckyPinball > Luck Number > Check Card Rules`：穷举1～5骰，验证两骰25／10／1分布、单张最高标准档、实例校验、选择锁定、批次成本和充能限流。
- `Run Acceptance Checks (Play Mode)`：固定骰面验证混合元素、头奖、重复火焰8秒、元素免疫、标准先滤免疫再选4只、快照与暂停、混号拒绝不变随机状态、共享连杀及250／350／450充能阈值。
- `Compare Single vs Combined (Play Mode)`：相同开局与压力策略，比较拆单和两张合出，记录批次数、耗牌数、档位、覆盖、击杀、越线和低装备时间；这是固定命中的脚本化对照，不冒充实际玩家试玩。
