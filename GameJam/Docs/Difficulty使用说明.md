# 难度系统中文使用说明

适用场景：`Assets/Scenes/Pinball.unity`。

本系统根据本局有效战斗时间，逐渐提高怪物刷新速度和下降速度。可以修改配置作为正式难度，也可以在本局临时调整参数、直接测试后期难度。游戏界面保留英文，本说明列出对应按钮名称。

## 1. 快速开始：直接测试第 5 分钟难度

1. 在 Unity 中打开 `Assets/Scenes/Pinball.unity`。
2. 在 Hierarchy 中选中挂有 `GameManager` 的对象。
3. 在 Inspector 底部找到 `Difficulty test`。
4. 将 `Preview / test time (s)` 填为 **300**。
5. 点击 **Play once at preview time**。
6. 等待正常发球后开始试玩。

使用默认配置时，难度立即采用第 300 秒的参数：刷怪间隔 **1 秒**，移动速度为基础速度的 **1.25 倍**。

这里仅把“难度采样时间”设为 300 秒。实际战斗时间仍从 0 开始，燃烧、眩晕、骰子开奖和补牌不会被快进，也不会直接生成五分钟积累的敌群。开局仍按配置生成 3 只怪。

此按钮只对这次启动生效。再次开始新局时，临时时间覆盖会清除；如果还要从后期难度开始，需要再次设置。

## 2. 正式难度配置在哪里

默认配置资产：

`Assets/Settings/DefaultDifficulty.asset`

使用入口：

`GameManager → Difficulty → Difficulty Config`

在 Project 窗口选中配置资产，即可在 Inspector 中修改。GameManager 引用哪份资产，本局就使用哪份配置。

| Inspector 字段 | 含义 | 默认值 |
|---|---|---:|
| Base Spawn Interval | 基础刷怪间隔，单位秒 | 2 |
| Base Descent Time | 以基础速度从出生线走到危险线所需的秒数 | 40 |
| Spawn Speed Multiplier | 刷怪速度总倍率，越大刷得越快 | 1 |
| Move Speed Multiplier | 移动速度总倍率，越大下降越快 | 1 |
| 阶段表 Time (s) | 该阶段的战斗时间 | 见下表 |
| 阶段表 Spawn speed | 该阶段的刷怪速度倍率 | 见下表 |
| 阶段表 Move speed | 该阶段的移动速度倍率 | 见下表 |

默认阶段：

| 战斗时间 | 刷怪阶段倍率 | 移动阶段倍率 |
|---|---:|---:|
| 0 秒 | 1.00 | 1.00 |
| 30 秒 | 1.00 | 1.00 |
| 90 秒 | 1.25 | 1.05 |
| 180 秒 | 1.60 | 1.15 |
| 300 秒 | 2.00 | 1.25 |
| 480 秒 | 2.50 | 1.40 |

相邻阶段之间平滑线性变化，不会等到阶段时间才突然跳变。早于第一阶段使用第一行，超过最后阶段使用最后一行。

计算方式：

- 当前刷怪间隔＝基础刷怪间隔 ÷ 阶段刷怪倍率 ÷ 刷怪总倍率。
- 基础移动速度＝出生线到危险线的距离 ÷ 基础下降时间。
- 当前移动速度＝基础移动速度 × 阶段移动倍率 × 移动总倍率。

例如，第 300 秒的阶段刷怪倍率为 2。如果再把刷怪总倍率设为 1.5，刷怪间隔就是 `2 ÷ 2 ÷ 1.5 ≈ 0.667 秒`。

### 编辑阶段表

- 点击列表底部 **＋**：新增阶段。
- 选中一行后点击 **－**：删除阶段。
- 点击 **Duplicate selected stage**：复制所选行的倍率，并为新行安排时间。
- 拖动行左侧手柄：调整行的位置。

阶段时间必须非负，并按从小到大严格递增。拖动后请检查时间顺序。

至少保留一个阶段。间隔、下降时间和所有倍率必须是有限正数。Inspector 会显示具体错误；配置无效时，运行时暂用完整的默认配置，不会自动改写你的资产。修正错误后，会重新使用所填参数。

### 制作不同难度版本

1. 在 Project 窗口选中默认配置。
2. 使用 Unity 的 Duplicate 命令复制资产，并重命名，例如 `EasyDifficulty`、`HardDifficulty`。
3. 分别修改副本的参数。
4. 把需要的资产拖入 GameManager 的 `Difficulty Config`。

## 3. 预览某个时间的难度

选中配置资产，在 `Difficulty preview` 中填写：

- **Sample time (seconds)**：想查看的难度时间。
- **Spawn-to-danger distance (m)**：出生线到危险线的距离；默认场景为 14.5 米。

预览显示以下结果：

| 显示项 | 含义 |
|---|---|
| Spawn interval | 当前刷怪间隔 |
| Theoretical attempts / minute | 理论每分钟生成尝试次数，不等于实际生成数量 |
| Move speed multiplier | 阶段倍率与配置总倍率相乘后的移动倍率 |
| Movement speed | 当前下降速度，单位米／秒 |
| Fixed-speed traversal time | 假设一直维持此速度、没有眩晕和阻挡，走完全程所需时间 |

下方两张曲线分别展示刷怪倍率和移动倍率的变化。

GameManager Inspector 中也有数值预览，并会自动读取场景里的出生线与危险线距离。如果修改过场地尺寸，优先使用这里核对速度。

仅修改预览时间不会改变运行难度。运行期间点击 **Use preview time in this run** 才会实际应用。

## 4. F8 战斗调试面板

该面板仅在 Unity 编辑器和 Development Build 中启用。正式非开发构建不启用。

进入游戏后，先点击 Game 视图使其获得键盘焦点，再按 **F8** 展开或收起。拖动面板标题栏可以移动位置。

### 显示的数据

| 英文显示 | 中文含义 |
|---|---|
| Combat time | 实际累计的有效战斗时间 |
| Difficulty time | 当前用于查阶段表的时间，以及当前模式 |
| Spawn interval | 当前刷怪间隔 |
| Move multiplier / Speed | 当前移动倍率与下降速度 |
| Living enemies | 场上存活怪物数量 |
| Last 30s · Spawned / Killed | 最近 30 秒有效战斗时间内，成功生成和击杀的怪物数量 |
| Mean completed refill interval (30s) | 最近 30 秒内完成的补牌间隔平均值；没有样本显示“—” |

开局生成的怪物计入成功生成数量。补牌间隔从满手首次出牌时开始计算；若仍缺牌，后续间隔从上一次补牌完成时开始。满手等待时间不计入补牌间隔。

### 临时修改速度

1. 在 **Spawn** 填写临时刷怪总倍率。
2. 在 **Move** 填写临时移动总倍率。
3. 点击 **Apply multipliers** 应用。

这里的数值会**替代配置资产中的总倍率**，阶段倍率仍正常参与计算。例如，配置的刷怪总倍率原本为 2，在面板填 1 并应用后，本局临时总倍率为 1，而不是再乘一次 1。

点击 **Reset temporary multipliers** 可取消临时倍率，恢复使用配置资产中的总倍率。

### 指定、冻结和恢复难度

| 操作 | 结果 |
|---|---|
| Sample time (s) 填 300，点击 Use specified time | 固定按第 300 秒采样难度，实际战斗继续计时 |
| Freeze difficulty | 固定当前正在使用的采样时间，难度停止随时间增长 |
| Restore automatic | 清除时间覆盖，立即按当前实际战斗时间采样 |

例如，实际已经战斗 100 秒，将难度指定为 300 秒后继续玩了 20 秒，再恢复自动，系统会使用实际第 **120 秒** 的难度。

**Restore automatic 只恢复时间模式，不会取消临时倍率。** 如果要完全恢复配置的正常运行方式，还需点击 **Reset temporary multipliers**。

F8 面板不会修改配置资产。重新开始一局会清除临时倍率与时间覆盖。

## 5. 正式修改与临时调试的区别

| 修改方式 | 作用范围 | 是否修改资产 |
|---|---|---|
| Inspector 修改 DifficultyConfig | 正式参数，运行中也立即影响后续刷怪和所有存活怪物 | 是 |
| F8 面板修改倍率、指定时间或冻结 | 当前这一局 | 否 |
| Inspector 点击 Play once at preview time | 本次启动的难度时间覆盖 | 否 |

**运行期间对 ScriptableObject 资产的修改会保留，不会因为退出 Play Mode 自动还原。** 临时试数值时使用 F8 面板；确定要作为正式难度时，再修改配置资产。

如果 F8 临时倍率仍在生效，修改资产中的对应总倍率不会立即显现；先点击 Reset temporary multipliers 再观察。

## 6. 刷怪和移动的实际行为

- 刷怪间隔控制的是“生成尝试”，每次仍沿用原有概率和位置检测，因此实际生成数量可能更少。
- 出生区被堵住时，本次尝试会消耗，不会囤积。空位恢复后按正常节奏继续，不会补出堵塞期间积攒的怪物。
- 调速不会清空当前刷怪进度。例如已完成 50%，调整后仍从 50% 继续，只改变剩余进度的完成速度。
- 开局 3 只怪物与周期刷怪分开处理，周期进度从 0 开始。
- 所有存活怪物使用当前统一下降速度，但眩晕和前后排间距约束仍有效。后排被挡住时可能停下，其他横向路径仍可下降。
- 暂停、等待发球和游戏结束时，战斗计时与周期刷怪进度停止。
- 损失生命后继续沿用本局时间；新开一局从 0 开始。

## 7. 默认参数速查

以下速度按当前场景 14.5 米路径计算；两项总倍率均为 1。

| 难度时间 | 刷怪间隔 | 移动倍率 | 下降速度 |
|---|---:|---:|---:|
| 0 秒 | 2.000 秒 | 1.000 | 0.3625 米／秒 |
| 60 秒 | 约 1.778 秒 | 1.025 | 约 0.3716 米／秒 |
| 300 秒 | 1.000 秒 | 1.250 | 约 0.4531 米／秒 |
| 480 秒及以后 | 0.800 秒 | 1.400 | 0.5075 米／秒 |
